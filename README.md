# C 语言核心笔记 · 网页版

一份可以离线使用的 C 语言复习笔记。单文件、双击即开，不用联网、不用注册、不装环境。

## 内容

- **50 节**，分 5 层按依赖顺序排列：字节与地址 → 程序如何成立 → 内存的两种活法 → 进出程序 → 408 实战
- **137 个代码区**（87 段代码 + 50 段输出样例）
- **243 条坑**，分布在 49 张「错误写法 / 正确写法 / 为什么」三列对照表里
- 6 个视图：体系图、通读、只看坑、概念索引、附录、进度
- 5 条路线：C 语言入门（37 节）、数据结构 408（13 节）、全量（50 节）、408 冲刺（32 节）、急救（≤ 1 天）
